# Deployment Guide — Alpha Cyber\n\n## Vercel Setup\n1. Connect repo to Vercel\n2. Set env vars: DATABASE_URL, SESSION_SECRET, NODE_ENV=production\n3. Build command: pnpm install && pnpm --filter @workspace/api-spec run codegen && pnpm --filter @workspace/alpha-cyber run build\n4. Output directory: artifacts/alpha-cyber/dist\n\n## GitHub Actions Workflow\nWorkflow file is ready at .github/workflows/deploy.yml\nAdd secrets: VERCEL_TOKEN, VERCEL_ORG_ID, VERCEL_PROJECT_ID\n\nNote: To push the workflow file, your token needs the 'workflow' scope.
