قم ببناء منصة OSINT احترافية متكاملة باسم "Alpha Cyber" مع الخصائص التالية:

**المتطلبات الأساسية للمشروع:**
- منصة ويب كاملة مع Frontend احترافي و Backend قوي
- قاعدة بيانات PostgreSQL لتخزين المستخدمين والصلاحيات والسجلات
- نظام مصادقة متقدم عبر رمز سري Access Code مع صلاحيات تحكم كاملة
- واجهة Dashboard احترافية للمشرفين
- دعم كامل للجوال Responsive Design بتصميم عصري

**نظام الدخول والصلاحيات:**
1. صفحة دخول تطلب Access Code فقط (بدون اسم مستخدم أو كلمة مرور)
2. لوحة تحكم للمشرف تمكنه من:
   - إنشاء وتفعيل وتعطيل رموز الدخول
   - تحديد عدد مرات استخدام كل رمز
   - تحديد تاريخ انتهاء صلاحية الرمز
   - مراقبة عدد المستخدمين النشطين حالياً
   - قطع اتصال أي مستخدم فورياً
3. سجل كامل لكل عملية دخول (التاريخ، الوقت، IP، المتصفح، الجهاز، الدولة)
4. إمكانية إيقاف وتشغيل الموقع بالكامل من لوحة التحكم

**الأدوات المطلوب دمجها وتشغيلها من داخل المنصة:**

يجب تثبيت وتشغيل الأدوات التالية كـ Python packages أو عبر API/CLI مع واجهة موحدة:

1. **Maigret** - البحث عن حسابات عبر منصات متعددة
2. **Social Analyzer** - تحليل الملفات الشخصية الاجتماعية
3. **Blackbird** - البحث عن حسابات عبر 600+ موقع
4. **Holehe** - التحقق من تسجيل البريد الإلكتروني في الخدمات
5. **SpiderFoot** - منصة OSINT آلية شاملة
6. **Sherlock** - البحث عن أسماء المستخدمين عبر الشبكات الاجتماعية
7. **Telespotter** - تحليل تيليجرام
8. **Phoneinfoga** - جمع معلومات عن أرقام الهواتف
9. **DIGI-NETRA** - تحليل البصمة الرقمية
10. **Enhanced Mobile Tracker** - تتبع الأجهزة المحمولة
11. **Phunter** - جمع معلومات الهاتف
12. **DetectDee** - الكشف عن حسابات منسية
13. **Tele-Trace** - تتبع حسابات تيليجرام
14. **TeleOSINT** - استخبارات تيليجرام
15. **Spyder** - زاحف ويب متقدم
16. **Telemetrio** - تحليل قنوات تيليجرام
17. **Telepathy** - تحليل شبكات تيليجرام
18. **Telegram Group Scraper (Apify)** - استخراج بيانات مجموعات تيليجرام
19. **Telegram Profile Scraper (Apify)** - استخراج بيانات ملفات تيليجرام

**نظام البحث المركب المتقدم:**
- إمكانية إدخال هدف واحد (اسم مستخدم، بريد إلكتروني، رقم هاتف، أو اسم كامل)
- تشغيل الأدوات المناسبة تلقائياً بناءً على نوع الهدف
- تشغيل الأدوات بشكل متزامن Concurrently وليس بشكل متسلسل
- دمج النتائج تلقائياً في تقرير واحد منسق
- إزالة النتائج المكررة تلقائياً
- عرض النتائج في واجهة تفاعلية مع:
  - تبويبات لكل أداة
  - عرض موحد للنتائج
  - إمكانية تصدير التقرير كـ PDF و CSV و JSON
  - رسوم بيانية وإحصائيات

**الواجهة والتصميم Frontend:**
- تصميم عصري داكن Cyberpunk/Matrix Theme
- React.js مع Tailwind CSS
- Animations احترافية وسلسة
- Dashboard مع إحصائيات حية Real-time
- جداول متقدمة مع بحث وفلترة وتصدير
- Dark/Light mode
- دعم اللغة العربية والإنجليزية
- Mobile-first responsive design
- شريط تقدم حي Live Progress Bar لكل عملية بحث
- إشعارات Toast notifications

**الـ Backend:**
- Node.js مع Express.js أو Python مع FastAPI
- WebSocket للـ Real-time updates
- Rate limiting متقدم
- نظام Queue لإدارة المهام الثقيلة باستخدام Bull/BullMQ
- Redis للـ caching
- تخزين النتائج في قاعدة البيانات مع إمكانية استرجاعها

**الأمان:**
- تشفير جميع البيانات الحساسة
- HTTPS only
- CORS محدد
- حماية ضد SQL Injection و XSS
- سجلات أمان كاملة Audit Logs
- حماية ضد محاولات الدخول المتكررة

**النشر التلقائي:**
- إعداد GitHub Actions workflow للنشر التلقائي
- ربط مباشر مع Vercel عبر GitHub integration
- إعداد ملف vercel.json للإعدادات
- نشر تلقائي عند كل push للـ main branch
- متغيرات البيئة Environment Variables آمنة
